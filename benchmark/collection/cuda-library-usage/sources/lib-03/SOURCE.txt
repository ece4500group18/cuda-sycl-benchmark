cuTENSOR tensor contraction example computing:
C_{m,u,n,v} = alpha * A_{m,h,k,n} B_{u,k,v,h} + beta * C_{m,u,n,v}
This represents a high-dimensional tensor contraction workload used in HPC and deep learning.
It exercises CUTENSOR library APIs for index-based tensor operations.
This case is suitable for CUDA→SYCL migration benchmarking due to:
- complex tensor index mapping
- multi-operand contraction
- high memory reuse patterns
- direct mapping to tensor algebra workloads in AI/HPC
