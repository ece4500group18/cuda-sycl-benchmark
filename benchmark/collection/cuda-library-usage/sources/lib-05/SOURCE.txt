cuTENSOR tensor permutation example.

Computes:
C_{c,w,h,n} = alpha * A_{w,h,c,n}

Representative tensor layout transformation workload.

This example performs NCHW <-> NHWC style tensor permutation while transferring
data between host and device memory.

Key migration challenges:
- tensor index remapping
- layout transformation
- descriptor construction
- memory ordering correctness
