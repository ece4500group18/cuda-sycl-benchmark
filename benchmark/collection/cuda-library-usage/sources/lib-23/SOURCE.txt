Snapshot contains gemm.cu together with required helper files and matrix generation utilities. 

Demonstrates distributed GEMM using cuBLASMp, MPI, NCCL communicators, distributed matrix descriptors, matrix gather/scatter operations, and correctness verification against a reference result. 

Requires a multi-process MPI execution environment and cuBLASMp installation.
