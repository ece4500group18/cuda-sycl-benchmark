Demonstrates overlapping host-device memory transfers and kernel execution using multiple CUDA streams. 

Includes pinned host memory allocation via cudaMallocHost and cudaHostRegister, event-based timing, asynchronous memcpy operations, and stream concurrency. 

Correctness is verified using the built-in correct_data() routine. 

No external datasets required.
