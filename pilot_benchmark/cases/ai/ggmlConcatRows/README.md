# ggml row concat

Concatenate two row-major tensors along the column dimension, adapted from ggml CUDA concat kernels.

Source project: ggml-org/llama.cpp

Source URL: https://github.com/ggml-org/llama.cpp/blob/master/ggml/src/ggml-cuda/concat.cu

License: MIT

Extraction notes: Standalone tensor layout transformation inspired by llama.cpp/ggml concat.cu.
